Program Realisasi Belanja Modal Bangunan

Monitoring pagu, kontrak, progres fisik, pembayaran, dan sisa anggaran kegiatan bangunan.

Identitas Program

Data tersimpan di penyimpanan browser pada komputer ini. Ekspor CSV secara berkala sebagai cadangan.
